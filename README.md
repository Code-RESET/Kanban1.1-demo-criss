# Demo · Trazabilidad de piezas (Kanban) v1.1

Demo interactiva para fabricación de gabinetes eléctricos: muestra cómo cada pieza se rastrea por estación con código QR, cómo se detecta un cuello de botella y cuándo un gabinete tiene su kit completo para ensamble.

**Ver demo:** https://code-reset.github.io/Kanban1.1-demo-criss/

- Datos de ejemplo. No guarda información ni se conecta a ninguna base de datos.
- Un solo archivo (`index.html`), sin instalación.
